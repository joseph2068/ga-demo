# 財務投資追蹤 App

純前端、免安裝的收支與投資紀錄工具，資料儲存在瀏覽器 `localStorage`。

## 使用方式

直接用瀏覽器開啟 `index.html`，或啟動任一靜態伺服器：

```bash
cd finance-tracker
python3 -m http.server 8080
# 開啟 http://localhost:8080
```

## 功能

- **收入**：日期、類別（薪資／接案副業／被動收入／其他）、金額、備註
- **支出**：日期、類別、金額、備註。當類別為「學習課程／買書／商會／社群」時，
  額外顯示**變現欄位**（是否已變現、變現金額、變現日期、變現說明），用來追蹤這筆
  自我投資最終有沒有轉化成實際收入或機會
- **自我投資變現分析**：彙整所有自我投資類支出，計算變現筆數、變現總額與投資報酬率
- **投資組合**：日期、項目名稱、類型（股票／ETF／基金／加密貨幣／房地產／其他）、
  投入成本、目前市值，自動計算損益與報酬率
- **儀表板**：關鍵指標卡片 + 近 6 個月收支趨勢圖、支出類別分佈、變現分析、投資組合分佈
- **資料匯出／匯入**：可將所有資料匯出為 JSON 備份，或匯入還原

所有資料僅存在本機瀏覽器，不會上傳到任何伺服器。
